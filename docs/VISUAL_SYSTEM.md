# Визуальная система

Каждый параметр рендера — непрерывная функция `Mood` и весов режимов. Каждое решение пишется в `decisions[]` как «вход → правило → результат» и видно на странице дня.

## Константы дневника (одинаковы на всех днях)
- Постер 1080×1920, поля 6%, сетка 12 колонок.
- Слева сверху дата в JetBrains Mono: `21.11.2026 · сб · вечер`; справа номер страницы `№ 004`.
- Внизу название (Cormorant Garamond), над ним одна рукописная строка (Caveat), под ним служебная строка «режим NN · режим NN» и пять точек палитры дня.
- Одна общая бумага: процедурная фактура (пятна + волокна + мелкий шум) не зависит от дня. Меняются только её тон (18% от светов дня) и плотность.

## Mood → режимы (`style/modes.ts`)
Сырые веса, затем возведение в квадрат и нормировка (сумма = 1):

| Режим | Формула (сокращённо) |
|---|---|
| Импрессионизм | позитив × покой^1.2 × (0.35 + 0.65·тепло) |
| Геометрия | arousal² × (0.55 + 0.45·|valence|) × (1 − 0.5·близость) |
| Плёнка | 0.85·ностальгия + вечер/ночь + 0.35·негатив + «светлая грусть» |
| Минимализм | (1 − social)^1.6 × покой × (0.6 + 0.4·холод) |
| Коллаж | social × (0.35 + 0.65·arousal) × много фото × позитив |

## Палитра (`style/palette.ts`)
- Основа — k-means на 5 цветов в LAB по hero-фото. Без фото используется таблица сезон × время суток.
- Тепло сдвигает b*/a*, arousal умножает хрому, valence меняет **только светлоту**. Грусть не красит день в синий: она убирает насыщенность и даёт больше воздуха.
- Split-toning: тени берутся из самого тёмного кластера, света — из самого светлого, оба подкрашены теплом дня. Чернила — это тень с насыщенностью от arousal.

## Параметры (`style/rules.ts`)
| Переменная | Правило |
|---|---|
| Экспозиция | +0.14·valence, −0.18 ночью, +импрессионизм |
| Контраст | 0.92 + 0.32·arousal + 0.25·геометрия − импрессионизм − плёнка |
| Насыщенность | 0.78 + 0.32·arousal + 0.14·valence − плёнка − минимализм + коллаж |
| Мазок Кувахары | радиус 3 + 12·импрессионизм + 3·плёнка…; сила 0.3 + 1.2·импрессионизм… |
| Зерно / halation / засветка | растут с плёнкой, ностальгией и ночью |
| Воздух (масштаб фото) | 0.9 − 0.5·минимализм − «светлая грусть» + геометрия |
| Кадрирование | насыщенный день тянет кадр к 4:5, тихий оставляет исходную пропорцию |
| Край фото | растворение = импрессионизм; рваный край = коллаж + плёнка; белая рамка отпечатка = плёнка + коллаж |
| Типографика | трекинг растёт с минимализмом, вес — с геометрией и arousal, курсив — при плёнке и импрессионизме, тонкая линия под шапкой — при минимализме или геометрии |

## Название дня (`style/title.ts`)
Без LLM: место, детали (вещи, а не люди) и обстоятельства («перед сдачей», «без будильника») ищутся по словарю основ. Шаблоны перебираются по порядку: обстоятельство → место + деталь → время + место → … → время + месяц. Название — 3–7 слов, без повторов в архиве.

## Конфликты
Если текст и фото расходятся по валентности, получается «светлая грусть»: плёнка +0.3, засветка +0.2, тёплые тени, больше воздуха. Серого усреднения нет.
