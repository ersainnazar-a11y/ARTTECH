# Дневник атмосферы

Личный дневник: текст о дне + фото + песня превращаются в воспоминание (постер 9:16), которое передаёт атмосферу дня. Визуал строится процедурным WebGL2-пайплайном по объяснимым правилам. Работает без сети и без ключей.

```bash
npm install && npm run dev
```

- `npm run build` — проверка типов и сборка
- `node scripts/make-test-audio.mjs` — синтетические треки с известными BPM и тональностью
- `npm run shoot` — самопроверка без ключа: тестовые дни с музыкой, FPS воспоминания → `shots/`
- `node scripts/shoot-llm.mjs` — проверка LLM-пути на mock-сервере (повтор, fallback, ирония, конфликты)

Документация: [docs/VISUAL_SYSTEM.md](docs/VISUAL_SYSTEM.md), [docs/TECHNIQUES.md](docs/TECHNIQUES.md), [docs/TOOLS.md](docs/TOOLS.md).

Статус: **фаза 4**. LLM-анализ текста, названия и подписи через OpenAI-совместимый endpoint (ключ в Настройках, только в браузере) с валидацией, повтором и fallback на правила; конфликты как приёмы. Ранее: пять режимов слоями и 15 мотивов. Пять режимов как смешиваемые слои (Кувахара, SDF-геометрия, плёнка, минимализм, коллаж карточками) и 15 процедурных мотивов, модулируемых музыкой. Ввод → анализ текста, фото и музыки (essentia.js в воркере, фрагменты iTunes) → DayStyle + decisions → WebGL (цветокоррекция, Кувахара, плёнка, бумага, типографика) → постер → бит-синхронное воспоминание 720×1280 с музыкой → архив в IndexedDB.
