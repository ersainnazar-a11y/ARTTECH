# Дневник атмосферы

Личный дневник: текст о дне, фото и песня превращаются в воспоминание — вертикальное видео под музыку и постер-страницу. Воспоминание передаёт атмосферу дня и сохраняется в папку дня с придуманным названием. Визуал строит процедурный WebGL2-пайплайн по объяснимым правилам. Работает без сети и без ключей; языковая модель — по желанию.

**Запуск одной командой:**

```bash
npm install && npm run dev
```

Нужен Node.js 20+ и браузер с WebGL2: Chrome или Edge. В них же работают запись прямо в папку (File System Access) и офлайн-рендер видео (WebCodecs). В остальных браузерах день сохраняется ZIP-архивом.

## Что внутри
- **Анализ:** текст (словарь русских основ или LLM с валидацией), фото (k-means в LAB, свет, температура, края), музыка (essentia.js в Web Worker: BPM, биты, тональность, энергия; свой файл или 30-секундный фрагмент iTunes).
- **Визуальная система:** 5 художественных режимов смешиваются весами; 15 мотивов из слов дня, модулируемых музыкой; константы дневника одинаковы для всех дней.
- **Выход:** постер 1080×1920; видео 720×1280 со склейками на битах (WebM в реальном времени или покадровый MP4); папка дня; голос.
- **Архив:** лента, поиск, фильтр по месяцу, «Проверка лентой», «Рентген дня».

## Команды
- `npm run build` — проверка типов и сборка в `dist/` (пути относительные, сборка работает с любого хостинга)
- `npm run preview` — локальный просмотр сборки
- `node scripts/make-test-audio.mjs` — синтетические треки с известными BPM и тональностью для самопроверки
- `npm run shoot` — самопроверка без ключа: тестовые дни, FPS воспоминания, лента, «Проверка лентой», рентген → `shots/`
- `node scripts/shoot-out.mjs` — видео (оба пути), папка дня (OPFS), ZIP
- `node scripts/shoot-llm.mjs` — LLM-путь на mock-сервере (повтор, fallback, ирония, конфликты)
- `node scripts/smoke-dist.mjs` — дымовая проверка собранной версии

## Деплой
- **GitHub Pages:** запушить в ветку `main` публичного репозитория и в настройках репозитория выбрать Pages → Source: GitHub Actions. Workflow `.github/workflows/deploy.yml` соберёт и опубликует `dist/`.
- **Vercel:** импортировать репозиторий — Vite определится автоматически (build: `npm run build`, output: `dist`).

Ключи API в репозиторий не попадают: провайдер и ключ задаются в «Настройках» и хранятся только в браузере.

*Настроение определяется алгоритмом по словам, фото и музыке и не является психологической оценкой.*
